# Xoso88 web

Bản web đầu tiên là static site, được triển khai bằng GitHub Pages.

- Source: `web/index.html`
- Deployment: `.github/workflows/pages.yml`
- Dữ liệu thật chưa được hard-code vào giao diện.
- Kết quả chỉ được nối vào UI sau khi pipeline đạt `VALIDATED` và có provenance.

## Local preview

Mở `web/index.html` trực tiếp trong trình duyệt hoặc chạy một static server từ thư mục gốc repository.
